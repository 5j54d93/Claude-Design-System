主題架構

Chapter 01 — data-theme / data-mode 與 HSL 變數機制

claude.ai 的主題由 <html> 上兩個 attribute 控制：

<html data-theme="claude" ← claude（主站）/ console（開發者後台） data-mode="auto"> ← light / dark / auto（跟隨系統） <body class="bg-bg-100 text-text-100 font-ui">

核心慣例：HSL 三元組

所有顏色以「不含 hsl() 包裝的 HSL 三元組」存於變數，取用時組合透明度：

--bg-100: 48 33.3% 97.1%; /* 定義 */ background: hsl(var(--bg-100)); /* 不透明使用 */ border-color: hsl(var(--border-200) / 30%); /* 任意透明度 ← 邊框慣用 */
最重要的慣例：邊框幾乎從不使用不透明色，而是「深色 token + 低透明度」。亮模式用近黑 #1f1e1d、暗模式用米白 #dedcd1，各配 10–30% 透明度。

本頁右上的 🌙 按鈕就是切換 data-mode — 全站所有顏色變數即時反應，無需任何其他改動。

雙站架構：App vs 行銷官網

Claude 視覺系統落在兩個站——claude.ai（App，Next.js）與 claude.com（官網，Webflow）。同一套品牌語言，機制不同；之後各章標「官網」的段落即 claude.com 專屬。

Chapter 11 — 快速開始與還原要點

快速開始

<html data-theme="claude" data-mode="auto" class="antialiased"> <head><link rel="stylesheet" href="tokens.css"></head> <!-- body 自動套 bg-bg-100 / text-text-100 / font-ui -->

Tailwind 對應 config（`hsl(var(--x) / <alpha-value>)` 接法）完整版見 docs/11-implementation.md。

還原視覺的 10 個關鍵

  • 米白不是白：頁面底 #faf9f5、卡片才是純白；暗模式底 #262624
  • AI 內容與標題用襯線、UI 用無襯線
  • 0.5px 髮絲框 + 深色 token 低透明度，絕少實色灰框
  • 暗模式調降字重（600→530），不只換色
  • 陰影極輕（黑 4–8%）；強調卡用彩色擴散光暈
  • 按壓 scale(0.985)；互動全部 100–200ms
  • 藍是互動色（focus / selection / 連結），橘是品牌與 CTA
  • 圓角階層：按鈕 8–9.6 → 容器 16 → 卡片 24px
  • 程式碼區塊永遠 One Dark 深色島
  • Dropdown/modal 標配 fade+zoom；行銷下拉用 clip-path 簾幕
